# Información sobre R

- R es un lenguaje de programación muy usado en
  estadística. RStudio es un programa para trabajar en R de forma cómoda.
  Necesitamos que instalen R y RStudio en sus computadoras para poder hacer
  los ejercicios de la materia. Si tienen dudas o problemas con la
  instalación, por favor mándennos mail a Manuela o Florencia.\
- Página de R: https://www.r-project.org/\
- Página de RStudio: https://rstudio.com/\
- Para quienes quieran ir instrucciones básicas de R:  [Guía básica de R](guiaR.pdf) y [Resumen de comandos de R](resumenR.pdf)
